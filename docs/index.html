Everything you expect from a modern chat app

Built as a single, dependency-free interface on top of the official NVIDIA NIM API.

STREAM

Streaming with live reasoning

Answers arrive token by token, with a collapsible reasoning panel for "thinking" models — no flicker, photosensitivity-friendly.

MARKDOWN

Full markdown rendering

Headings, lists, tables, quotes and code blocks with syntax highlighting and one-click copy.

/model

Self-updating model picker

The list syncs with the API at every launch: new text models appear, dead ones disappear. Keyboard-friendly picker with filter, like Opencode or Claude Code.

VISION

Send images

Paste, drop or attach images — analyzed by vision models, marked with a VISION badge in the picker.

MCP

MCP servers

Give the AI tools: local commands (stdio) or remote endpoints (Streamable HTTP), up to 8 tool rounds per answer.

i18n

6 languages

English, Français, Español, Deutsch, Italiano, Português — chosen at first launch, switchable anytime. The AI answers in your language.

HISTORY

Conversation history

Search, pin, rename, export to Markdown. Edit any message and regenerate, copy or delete anything.

AUTO

Smart conversation titles

The model names each conversation itself after the first exchange, in your language.

Verified text-generation models

Every model is probed on the API before joining the list — 14 at the moment, and the app keeps it current by itself.

Getting started

Three steps, about two minutes.

1

Download the app

Grab NvidiaBuildApp.exe from the GitHub releases — a single file, no installer.

2

Get a free API key

Create a free key at build.nvidia.com (NVIDIA account required).

3

Pick a language and chat

Choose your language on first launch, paste the key in Settings, pick a model with /model — done.

Frequently asked questions

Short answers, no fluff.

Is this an official NVIDIA product?

No. NVIDIA Build App is an unofficial fan project, not affiliated with, endorsed by, or sponsored by NVIDIA Corporation. NVIDIA and all related marks are trademarks of NVIDIA Corporation.

Is it free?

The app is free and open source (MIT). You need an API key from build.nvidia.com — creating one is free with an NVIDIA account.

Where is my data stored?

Conversations and settings stay on your computer (in AppData). Nothing is sent anywhere except your prompts to the NVIDIA API to generate answers.

Does it work on Mac or Linux?

Not yet — it is a Windows app. The code is open, so ports are welcome.
